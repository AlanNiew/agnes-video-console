# 高质量 AI 视频创作指南（实战手册）

> 基于 Agnes 平台多轮 0→1 实战沉淀（《末班车》短片 → 《画皮》10-15 分钟长片十轮迭代）。
> 本手册回答一个核心问题：**AI 视频怎样才算「好」，怎么稳定地做出「好」**。
> 平台操作细节（接口/限流/渲染参数）见 `CREATION_PLAYBOOK.md`；本文聚焦创作方法论。

## 一、创作心法：先想清楚「观众会记住什么」

技术再好，也救不了平庸的故事。动手前先问三个问题：

1. **一句话能说清吗？**——把故事压缩成一句：时空 + 主角 + 核心事件 + 情感落点。
   「深夜末班地铁，老清洁工捡到旧怀表，次日还给哭着寻找的失主小女孩——晨光第一次洒进站台。」
2. **观众看完记得什么？**——是某个画面（狞鬼执笔绘人皮）、某句台词、还是某种情绪（贪色招祸、忍辱回生）。把「记忆点」排进脚本。
3. **这个题材适合 AI 生成吗？**——AI 强于「场景/氛围/情绪意象」，弱于「精确动作/多角色长对话/文字细节」。题材扬长避短。**媒介上优先动画/风格化**（见 §3.5：动画规避真人写实的模型短板）。

**成片上限在创意这一步就定了**：文案含糊 → 全线平庸；文案具体到可拍摄 → 全线有戏。

## 二、剧本与叙事

### 2.1 长片结构：段落化 + 钩子

平台单项目有物理上限（12s/镜 × ≤20 镜 ≈ 4 分钟），10 分钟以上成片必须**拆段创作、最后拼接**：

- 每段是一个独立闭环：**建置 → 推进 → 收束**
- 段与段之间留「钩子」（悬念/预告），拼起来仍是完整故事
- 《画皮》拆 5 段：晨遇 → 妖影 → 破门 → 诛鬼 → 回生，每段 ~2.5 分钟

### 2.2 分镜节拍：每镜必须有「存在理由」

- 一镜一个**信息 / 情绪 / 动作节拍**——问自己：删掉这镜故事缺了什么？
- 开场镜负责「建立时空 + 主角出场」，结尾镜负责「收束情绪」
- 杜绝「为了凑时长」的空镜；环境镜要承担氛围与转场功能

### 2.3 旁白：连读成文，不是逐镜造句

说书/解说式旁白有个隐形标准——**全片旁白抽出来是一篇完整短文**：

- 旁白与画面**互补而非复述**（画面在演掏心，旁白别念「他掏心了」，说因果/心理）
- 一条时间线顺下来：每镜只讲这一镜推进的那一步
- 段落边界用「钩子句」收尾（“这一夜，浑然不觉窗外已悄悄聚起墨云”）

### 2.4 台词改写（对白化）

旁白骨架 + 关键对手戏镜转**角色台词**（一镜一人一句，画面人物开口讲）：

- 台词要带「角色口吻」，不是把旁白加引号
- 说话人必须与该镜画面主体一致（画面谁在特写，就谁说话）
- 其余镜保留旁白——全对白会让说书感消失，全旁白则角色无戏

## 三、一致性工程（AI 视频最大的坑）

AI 生成每次都是「新的随机」——**让角色/风格跨镜稳定，是质量的核心战场**。

### 3.1 角色一致性：种子图锚（最重要）

- **每个多次出镜的角色，必须有一张「种子图」**（外观定稿：脸型/服饰/发型/气质）
- 角色种子图要**同风格批量产出**（同一模型/同提示词体系），否则角色之间画风打架
- **每镜都要引用对应角色的种子图**（`<Picture N>`），禁止「这镜没他正脸就不锚」——远景小人也锚，服饰体态才稳
- 多角色同镜：`images=[角色A图, 角色B图]` + prompt 写清 `<Picture 1>` 指谁、`<Picture 2>` 指谁
- **种子图与成片风格校验**：种子图如果是「立绘/插画」，视频会往那个画风偏——要写实片就配写实种子图

### 3.2 风格一致性：全镜有锚 + 统一风格锚

风格漂移的病根是**裸文生镜**（无图参考，模型自由发挥）：

- **零裸文生原则**：人物镜引角色图；纯环境镜引「场景种子图」
- 场景种子图：每场景 1 张（古道/书斋/市集/庙/内室…），锁环境与色调
- 所有镜尾统一挂**同一句风格锚**（一字不改复制）：
  「写实真人电影感摄影，自然皮肤纹理，真实布料质感，胶片颗粒，浅景深。严禁卡通化、动漫化、插画…」
- 负面约束写进 prompt 比事后补救有效得多

### 3.3 动作自然度：别让角色像假人

静态立绘做参考 → 模型倾向「摆拍站姿」，一动就僵。解法：

- prompt 明确「参考图仅作外貌参考，本镜须自然行走/动作，绝不能模仿参考图僵硬姿态」
- 动作细化到可执行肢体：步伐匀称、双臂随步伐摆动、偶尔低头看路…
- **动作量与镜长匹配**：12s 镜可放 2-3 个连贯动作；动作复杂就缩短镜长
- 长镜会把动作缺陷放大——没把握的动作，宁用短镜组合规避

### 3.4 细节层失真：五类症状对症下药（《修表匠》/五部短片实拍沉淀）

AI 视频的「小细节失真」（零件凭空多一个、手指多一根、转身换件衣服、眼泪流成水柱、招牌写成乱码）观众一眼出戏，且**常被误当成统一的"模型不行"**。实际是五类根因、五类对策：

**① 可数物体恒常性/计数 → 模型系统性弱项 + prompt 措辞放大（可缓解不可根治）**
视频模型**无帧间物体追踪**（每帧独立生成再插值），对"桌上该有几颗螺丝"没有概念。prompt 措辞会显著放大：

- ❌ 递增/离散铺陈措辞：「逐件散落」「每一颗螺丝都被分类排列」「仿佛星河铺展」——都是"数量递增或大量离散点"语义，等于教模型多画。
- ✅ 封闭集合措辞：「软布上摆着**已拆下的 3 件零件**（后盖、发条盒、表盘），数量保持不变，不得新增或复制」——给死数量 + 明确禁止增生，明显收敛。
- 再叠：动作简化（单镜只做"撬开后盖"一个动作，不做"散落全过程"）+ 缩短镜头（5s 环绕微距最易翻车）。

**② 手部/解剖细节 → 模型弱项（基本不可根治，只能构图规避）**
手指数量、关节弯曲是全部视频模型的解剖盲区。prompt 写"五根手指"也锁不住。最有效对策是构图规避：

- 避免「手部微距 + 精细操作」（镊子夹小零件 = 最难构图）；
- 改俯拍桌面全景（手只入画一小角）或焦点给物件、手部出焦虚化；
- 用静态物件特写替代手部动作特写；手必须出镜时用中景（手小到看不清细节），别用特写送人头。

**③ 跨镜服色/服饰一致性 → 一致性工程缺失（可根治，流程问题）**
「上个镜头白衣服、下个镜头黑衬衫」不是模型随机，是锚没给够：

- **种子图带服色文字锚**：角色图 prompt 不能只写脸，必须写死服色三件套（如「深褐色粗布围裙 + 洗旧米白衬衫」）——否则模型对"衣服什么样"无约束，各镜自由发挥。
- **分镜 prompt 同步带服色锚**：图锚之外补一句服色文字锚（「他穿着那件深褐围裙」），跨镜多一道保险；单靠 `<Picture N>` 图锚会被各镜光照/机位带偏。
- **种子图风格 = 成片风格**：「角色立绘」式种子图服饰细节弱、偏插画，写实片必须写「写实电影剧照」类措辞。

**④ 流体/小物体物理 → 模型弱项（措辞救不了，只能构图规避）**
眼泪/水滴/烟雾/碎屑等流体与微粒，模型没有物理模拟器——「一滴泪滑落、坠入手背」这类**动态流体过程特写**（实拍《修表匠》镜 6）会生成成水流/拉丝/水柱，写「晶莹」「一滴」也没用。规避策略：

- **静态 > 动态**：把「滑落→坠落」的过程改为「悬在眼眶/悬而未落、灯光在泪珠上凝成一点光」，静态液珠模型可控得多；
- **借代情绪**：不直拍泪滴实体，拍光线在湿润眼角的反光、鼻翼翕动、喉结滚动、握紧又松开的手——情绪比液滴真实；
- 真要「流下」，让泪只在脸上留下**已存在的光泽泪痕**（静态结果），不要生成「正在流」的过程；
- 同类：烛泪、雨滴滑窗、血液滴落、水流——一律避免流体特写，用结果/氛围/替代物。

**⑤ 画面内文字/数字 → 模型弱项（必乱造或崩，能避则避）**
招牌、碑文、书法、号码等**画面内文字**，模型要么写成伪文字（乱码字符/伪日文）、要么随机造数字（五片质检实测并经复核：石碑凭空出现「819」与剧情「37 次」不符；街景招牌为伪日文；壁上书法半乱码；《修表匠》怀表刻字在双模型复现中亦均为伪汉字）。规避策略：

- **构图写「无文字」**：需要招牌/书籍/碑刻的场景，prompt 明确「招牌无文字/素面」「碑面无字」，或改用**近景/特写**（把招牌挤出画面）；
- **需要可读文字时后期做**：渲染后贴图/字幕叠字比模型直写可靠；
- 注意：宽街景对「无文字」指令的服从度低（实测重拍仍生造招牌），**改构图比改措辞更有效**。

> 五问判型：看到细节失真先判类——模型系统性弱项（计数/解剖/流体/文字 → 规避或接受）？prompt 措辞放大（改措辞）？锚缺失（补图锚/文字锚）？五类对策不同，判错型会白重拍。

### 3.5 媒介与风格定位：优先动画（v2.3.0 实测决策）

**核心决策：本项目 AI 视频以「动画/风格化」为主，真人写实谨慎用。** 依据：

- **真人写实 = 直撞模型全部系统弱项**：皮肤质感、手部解剖、微表情、流体（眼泪/汗）、细节恒常性（3.4 四类）——这些恰是当前所有视频模型的盲区，且**不可根治、只能规避**，真人特写无处可躲；
- **动画/风格化 = 把短板变风格**：笔触、剪影、留白、色块本身就是「不真实」的表达方式，模型的物理不准反而被读作「画风」；观众对虚拟形象不做像素级真实校验，容错度高；
- **实测对照**：《画皮》原片（水墨设色电影写实）细节常需逐镜返工；《画皮·动态漫画预告》（国风水墨动画）同类场景一次成片，观感明显更稳。

**风格规避手法**（不靠模型精准，靠语言与构图）：

- 复杂动作/流体/变形（掏心、剥皮、泪流）→ 用**剪影/逆光/墨色遮挡/留白**表现结果，不直拍过程；
- 远景/中景为主，人物特写只给「泪眼、相握的手」等安全局部；
- 色彩克制：单色墨为主，**强调色只留一两点**（血红/青绿），既出风格又降低色彩漂移风险。

**「新国风水墨动画」风格模板（首个沉淀风格，可直接复用）**：

- **风格锚**（全镜逐字复制）：`中国水墨动画，宣纸肌理，墨色浓淡皴擦，工笔勾线与淡彩渲染，留白构图，血红与青绿作强调色，电影级打光，浅景深，高细节`
- **主题库**：中国古典志怪（聊斋系：画皮/婴宁/聂小倩）为首选；可扩展武侠、仙侠、民俗寓言
- **角色图**：同风格锚产出的水墨角色设定图（含**双形态**时可各出一张，如「美人/鬼本相」），逐镜按角色注入
- **参数**：16:9、单镜 8-12s、说书式旁白（语速 0.9）、悬疑民乐/游戏配乐、fade 转场、白描字幕
- **叙事载体**：动态漫画预告片式（定格漫画构图 + 缓慢运镜 + 说书旁白）——单镜信息量大、节奏稳、适配 AI 长镜

**动画风格候选库（按 AI 胜率分级，v2.3.0 调研沉淀）**：

- 🟢 **高胜率（优先试）**：**日式赛璐璐 2D（anime cel shading，⭐ 四风格实测最佳）**、国风水墨/宣纸（✅ 已验证）、**中国连环画白描（⭐ 三场景复评最稳，见下）**、三渲二（toon shading / cel-shaded 3D，实测一般可接受）、水彩插画（watercolor，实测一般可接受）、**版画木刻（woodcut/engraving，⚡ 场景化：开阔大景/高对比逆光最强、拥挤近景崩）**、**油画厚涂（impasto，梵高风，⚡ 场景化：有天空/戏剧光线的外景出色）**、治愈绘本/蜡笔（⚠️ 会把成年角色童化）；
- 🟡 **中风险（需更强锚）**：像素风（⚠️ 跨场景不稳：庭院成立、大漠失效成普通平滑动画）、哥特暗黑童话（🌙 仅暗调氛围生效，无波顿式夸张造型，宜暗场景）、赛博/蒸汽朋克插画（🏙️ 仅都市/未来语境，否则反客为主改场景或只剩霓虹配色）、剪影动画、扁平矢量 motion graphics、欧漫 BD、**皮影/剪纸动画**（🔁 静帧复核：石桥/雨巷/云海三场景一致、剪纸质感与关节工艺到位，「一致性崩塌」不成立；局限=平面侧影无面部微表情、关节动画的运动稳定性未看片复核 → 民俗/剪影题材的特色可用款）；
- 🔴 **雷区（物理一致性要求高）**：定格黏土/毛毡/布偶（物体漂移颤动）、写实 3D CGI（恐怖谷，等同真人写实问题）、沙画（流体+精细控制双弱项）；
- ⛔ **实测弃用（多场景一致失效）**：**敦煌壁画·青绿山水**（矿物颜料/金线锚被写实压过 → 真人 + 青绿背景板，两场景均如此）。
- **高效试验法**：同一 15-20s 测试场景（1 角色 + 1 简单动作 + 1 环境），只换风格锚 + 对应角色图，跑多风格并排对比（已用此法完成四风格对比，见下）。

**四风格对比实测（三局两胜：石桥/雨巷/云海三场景，项目 #29+#30，2026-09，结论三轮一致）**：① **日式赛璐璐 2D 最佳**（动漫训练数据最充分）＞ ② 三渲二 ≈ ③ 水彩插画（「一般、可接受」）＞ ④ **皮影/剪纸最差（非特别委制不用）**（镂空关节 + 平面剪影一致性模型难维持）。→ **动画基准风格 = 日式赛璐璐 2D**（在已验证的国风水墨之外，第二个主力风格）。

> **皮影降级复核补记（2026-09，视觉模型抽帧）**：三场景（石桥/雨巷/云海）静帧复核显示④皮影的**剪纸质感与角色一致性均稳**、关节镂空是刻意的皮影工艺而非崩坏——「一致性差」的旧判在静帧上不成立；真正局限是**平面侧影无面部微表情**（表现力受限），且关节做动作时的运动稳定性**未看片复核**。结论：非「最差」，而是**特色题材型**——民俗/剪影叙事优先，普通表情戏不用；若要用，先拍一条测试片看运动。

**扩展 8 风格首轮筛选（项目 #31，场景：夜森林提灯旅人，2026-09，排序由**人工观看**给出）**：**白描 > 哥特暗黑童话 > 治愈绘本 > 赛博朋克 > 敦煌青绿 ≈ 梵高油画 ≈ 像素 > 木刻**。（多场景复评见下：木刻/梵高在开阔场景上调、像素/哥特跨场景不稳。）

**扩展 8 风格多场景复评（#32 春日庭园 成片-71 + #33 大漠孤旅 成片-72；视觉模型抽帧目视：每 2s 接触表 + 每风格中段高清帧连带二次抽样，2026-09）**——首轮排序按场景修正如下。⚠️ **运动平滑度未看视频**，仅帧间抽样核对，该维度仍以人工看片为准。

- **跨场景最稳（可作主力）**：
  - **白描**：三场景一致（#33 宣纸做旧质感最佳）；实际呈现为「连环画 + 水墨淡彩」而非纯线描，与国风水墨同源 → 稳定首选；
  - **治愈绘本/蜡笔**：两场景均干净讨喜，但会把成年角色**童化**（#32/#33 都变成小男孩）——角色为成人时慎用。
- **场景化威力型（强但挑场景）**：
  - **木刻**：开阔大景 + 高对比逆光=全场最强（#33 沙丘背影封面级）；拥挤近景（#31 夜森林）排线糊成一团 → **首轮垫底是场景之锅，开阔场景应上调**；
  - **梵高油画**：有天空/戏剧光线的外景=教科书级旋涡笔触（#33 红日沙海）；平淡内景=普通油画笔触；
  - **赛博朋克**：仅都市/未来语境成立，且会**反客为主改场景**（#32 把江南庭园变成霓虹街道）；非都市场景只剩霓虹配色（#33 沙漠）→ 要都市题材才用。
- **跨场景不稳（暂不作主力）**：
  - **像素**：#32 庭院成立（方块清晰、构图完整）；#33 大漠**直接失效**成普通平滑动画（两个抽样点一致）——与首轮设想的「像素稳定」相反；
  - **哥特暗黑童话**：只有「暗调氛围」生效、无波顿式夸张造型；暗场景可用（#31 排第 2 的由来），亮场景会变成写实暗调片（#32 春日同样发灰）。
- **弃用/需重调锚**：**敦煌壁画·青绿山水**——两场景均被写实压过（#32 真人 + 青绿背景板、#33 写实沙漠 + 奇幻红天），矿物颜料/金线锚失效；如仍要用需重写锚词再试。

**多场景可用性排序（视觉实测，2026-09）**：**白描 ≥ 治愈绘本（童化限制）> 木刻 ≈ 梵高（场景化）> 赛博（须都市）> 哥特（须暗场景）> 像素（不稳）> 敦煌（弃用）**。

**判据**：风格化的本质是「把模型的物理不精确读作画风」——笔触/留白/色块越强、越不依赖真实物理、且训练数据越充分的风格，胜率越高。

**风格评估量表（v2.3.0 固化，统一口径）**：5 维度各打 1–5 分，加权求和得「可用性分」——**≥4.0 主力 / 3.0–3.9 可用（分场景） / <3.0 弃用**。

| 维度              | 权重 | 评分要点                                                                       |
| :---------------- | :--- | :----------------------------------------------------------------------------- |
| **风格贴合**      | 30%  | 是否真呈现目标风格锚；跑偏重扣（须人工看图判断）                               |
| **运动稳定**      | 25%  | **须人工看视频/多帧**：抖动、变形、动作自然度、时序一致性（AI 视频最易翻车处） |
| **角色/结构保真** | 20%  | 脸手不崩、角色统一、无误伤（人工看大图）                                       |
| **跨场景一致性**  | 15%  | 换场景不塌（人工比对多场景）                                                   |
| **构图美感**      | 10%  | 画面成画、有美感、可进成片（人工）                                             |

评估纪律（避免误判）：

- **单帧不定论**：每风格至少跨 2–3 个场景、每场景抽多帧或看动图；**运动维度必须看视频**，不得凭单帧下结论。
- **人机分工**：AI 是否具备视觉能力**因模型而异**——**视觉模型（如 v4.1）可读图/看抽帧参与画面评估**；**纯文本模型只能给客观量化指标**（亮度/对比/饱和/边缘密度/帧间差，ffmpeg signalstats），不能判断美术好坏。用纯文本模型时，画面类结论（风格贴合/运动/保真/构图/跨场景）**必须由人给**，AI 不得编造。
- **记录**：评分 + 结论回填风格库；抽样帧有随机性（曾抽到片尾卡），需复核取样点。

## 四、镜头语言

### 4.1 景别节奏

同景别连排是大忌。一组戏按「全景建环境 → 中景给关系 → 近景/特写给情绪」推进，再拉开呼吸。相邻镜景别/机位要有变化，避免视觉重复。

### 4.2 衔接三法（按强度递进）

| 方法          | 适用                    | 实现                                                          |
| :------------ | :---------------------- | :------------------------------------------------------------ |
| **fade 黑场** | 一般切换（默认）        | 渲染 transition_type=fade，300-400ms 最稳，**无噪点叠加脏感** |
| **首尾帧链**  | 动作/视线需承接的相邻镜 | 镜 N 成片抽末帧 → 作为镜 N+1 的 `first_frame`，画面自然续接   |
| **机位承接**  | 同场景连续动作          | 分镜阶段就设计好：上镜结尾动作与下镜开头动作衔接              |

避坑：

- **dissolve（溶解）在高噪 AI 素材上会「斑斑点点」**（两套噪场互透）——温情片尚可，惊悚/高反差画面明显
- 首尾帧链是「上镜末帧」不是硬套两张图大变——差异大的两张图直接互变会跳变
- wipe 扫场风格偏「幻灯」，慎用

### 4.3 180° 轴线

相邻镜角色视线/运动方向保持一致，别越轴（对话 A 看右、下一镜 B 也在看右 = 两人同向）。

## 五、声音设计

### 5.1 层级

成片听感 = 旁白/对白（主） + BGM 铺底（次） + 自动响度归一。旁白 BGM 开闪避（duck）。

### 5.2 角色音色：身份感优先

- 旁白说书人一套音色；每个角色一套，**气质要能区分角色**（书生≠说书人≠妖）
- 音色试听不可省：搜「气质词」（知性温暖/沉稳/温柔动听/神秘），逐角色听 2-3 个再定
- 同角色全片一个音色；妖/鬼可用特殊处理音色建立恐怖感

### 5.3 对白同步：逐镜偏移

「统一 500ms 偏移」对旁白够用，对白会**声音早于口型**。解法：给对白镜的配音记录设 `offset_ms`
（约 1000-1500ms，等人物起幅开口），渲染器按镜生效，旁白镜保持默认。**对白必须贴开口时点，旁白无所谓**——这是两类声音的本质区别。

### 5.4 时长铁律

配音/旁白 ≤ 镜长秒数 × 4 字（TTS 约 4.3-5.2 字/秒）；配音时长 + 偏移 < 镜头实际时长，否则被截断。

## 六、技术执行 SOP

### 6.1 素材 URL：公网可达是第一关卡

上游模型只能拉「公网 http(s) URL」——本机文件/内网全不行，且有三道隐形门槛：

1. **端口白名单**：非标准端口（如 18293）直接拒绝，挂到 **80/443**
2. **体积**：1.5MB PNG 会下载超时（504），压缩到 **~200KB JPEG** 秒拉（视频参考用 1280 宽足矣）
3. **Range/代理兼容**：nginx 关代理缓冲、流式传输，避免下载中断

推荐自建文件服务器（download/列表公开、上传带认证）统一管理种子图，比第三方图床稳。

### 6.2 限流与排队

视频生成有上游限流（免费档 1 次/分钟）。62 镜 ≈ 65 分钟起步——**批量入队后台排队**，别逐镜干等；期间并行做配音/BGM/文案。503 `video_queue_full` 是瞬时限流，`retry` 接口带退避即可。

### 6.3 渲染配方

- 转场 fade；旁白偏移 500ms 默认（对白镜另设）；BGM 0.3-0.35 开闪避
- 字幕白描（white-outline）44 号最通用；志怪/纪录向可略小
- 响度无需手调：自动 loudnorm -16 LUFS

### 6.4 拼接与归档

多段 xfade（0.8s fade）拼接；字幕按各段实测时长重排时间轴；产物归档作品目录（成片/字幕/台词/海报）。
