# 高质量 AI 视频创作指南（实战手册）

> 基于 Agnes 平台多轮 0→1 实战沉淀（《末班车》短片 → 《画皮》10-15 分钟长片十轮迭代）。
> 本手册回答一个核心问题：**AI 视频怎样才算「好」，怎么稳定地做出「好」**。
> 平台操作细节（接口/限流/渲染参数）见 `CREATION_PLAYBOOK.md`；本文聚焦创作方法论。

## 一、创作心法：先想清楚「观众会记住什么」

技术再好，也救不了平庸的故事。动手前先问三个问题：

1. **一句话能说清吗？**——把故事压缩成一句：时空 + 主角 + 核心事件 + 情感落点。
   「深夜末班地铁，老清洁工捡到旧怀表，次日还给哭着寻找的失主小女孩——晨光第一次洒进站台。」
2. **观众看完记得什么？**——是某个画面（狞鬼执笔绘人皮）、某句台词、还是某种情绪（贪色招祸、忍辱回生）。把「记忆点」排进脚本。
3. **这个题材适合 AI 生成吗？**——AI 强于「场景/氛围/情绪意象」，弱于「精确动作/多角色长对话/文字细节」。题材扬长避短。

**成片上限在创意这一步就定了**：文案含糊 → 全线平庸；文案具体到可拍摄 → 全线有戏。

## 二、剧本与叙事

### 2.1 长片结构：段落化 + 钩子

平台单项目有物理上限（12s/镜 × ≤20 镜 ≈ 4 分钟），10 分钟以上成片必须**拆段创作、最后拼接**：

- 每段是一个独立闭环：**建置 → 推进 → 收束**
- 段与段之间留「钩子」（悬念/预告），拼起来仍是完整故事
- 《画皮》拆 5 段：晨遇 → 妖影 → 破门 → 诛鬼 → 回生，每段 ~2.5 分钟

### 2.2 分镜节拍：每镜必须有「存在理由」

- 一镜一个**信息 / 情绪 / 动作节拍**——问自己：删掉这镜故事缺了什么？
- 开场镜负责「建立时空 + 主角出场」，结尾镜负责「收束情绪」
- 杜绝「为了凑时长」的空镜；环境镜要承担氛围与转场功能

### 2.3 旁白：连读成文，不是逐镜造句

说书/解说式旁白有个隐形标准——**全片旁白抽出来是一篇完整短文**：

- 旁白与画面**互补而非复述**（画面在演掏心，旁白别念「他掏心了」，说因果/心理）
- 一条时间线顺下来：每镜只讲这一镜推进的那一步
- 段落边界用「钩子句」收尾（“这一夜，浑然不觉窗外已悄悄聚起墨云”）

### 2.4 台词改写（对白化）

旁白骨架 + 关键对手戏镜转**角色台词**（一镜一人一句，画面人物开口讲）：

- 台词要带「角色口吻」，不是把旁白加引号
- 说话人必须与该镜画面主体一致（画面谁在特写，就谁说话）
- 其余镜保留旁白——全对白会让说书感消失，全旁白则角色无戏

## 三、一致性工程（AI 视频最大的坑）

AI 生成每次都是「新的随机」——**让角色/风格跨镜稳定，是质量的核心战场**。

### 3.1 角色一致性：种子图锚（最重要）

- **每个多次出镜的角色，必须有一张「种子图」**（外观定稿：脸型/服饰/发型/气质）
- 角色种子图要**同风格批量产出**（同一模型/同提示词体系），否则角色之间画风打架
- **每镜都要引用对应角色的种子图**（`<Picture N>`），禁止「这镜没他正脸就不锚」——远景小人也锚，服饰体态才稳
- 多角色同镜：`images=[角色A图, 角色B图]` + prompt 写清 `<Picture 1>` 指谁、`<Picture 2>` 指谁
- **种子图与成片风格校验**：种子图如果是「立绘/插画」，视频会往那个画风偏——要写实片就配写实种子图

### 3.2 风格一致性：全镜有锚 + 统一风格锚

风格漂移的病根是**裸文生镜**（无图参考，模型自由发挥）：

- **零裸文生原则**：人物镜引角色图；纯环境镜引「场景种子图」
- 场景种子图：每场景 1 张（古道/书斋/市集/庙/内室…），锁环境与色调
- 所有镜尾统一挂**同一句风格锚**（一字不改复制）：
  「写实真人电影感摄影，自然皮肤纹理，真实布料质感，胶片颗粒，浅景深。严禁卡通化、动漫化、插画…」
- 负面约束写进 prompt 比事后补救有效得多

### 3.3 动作自然度：别让角色像假人

静态立绘做参考 → 模型倾向「摆拍站姿」，一动就僵。解法：

- prompt 明确「参考图仅作外貌参考，本镜须自然行走/动作，绝不能模仿参考图僵硬姿态」
- 动作细化到可执行肢体：步伐匀称、双臂随步伐摆动、偶尔低头看路…
- **动作量与镜长匹配**：12s 镜可放 2-3 个连贯动作；动作复杂就缩短镜长
- 长镜会把动作缺陷放大——没把握的动作，宁用短镜组合规避

## 四、镜头语言

### 4.1 景别节奏

同景别连排是大忌。一组戏按「全景建环境 → 中景给关系 → 近景/特写给情绪」推进，再拉开呼吸。相邻镜景别/机位要有变化，避免视觉重复。

### 4.2 衔接三法（按强度递进）

| 方法          | 适用                    | 实现                                                          |
| :------------ | :---------------------- | :------------------------------------------------------------ |
| **fade 黑场** | 一般切换（默认）        | 渲染 transition_type=fade，300-400ms 最稳，**无噪点叠加脏感** |
| **首尾帧链**  | 动作/视线需承接的相邻镜 | 镜 N 成片抽末帧 → 作为镜 N+1 的 `first_frame`，画面自然续接   |
| **机位承接**  | 同场景连续动作          | 分镜阶段就设计好：上镜结尾动作与下镜开头动作衔接              |

避坑：

- **dissolve（溶解）在高噪 AI 素材上会「斑斑点点」**（两套噪场互透）——温情片尚可，惊悚/高反差画面明显
- 首尾帧链是「上镜末帧」不是硬套两张图大变——差异大的两张图直接互变会跳变
- wipe 扫场风格偏「幻灯」，慎用

### 4.3 180° 轴线

相邻镜角色视线/运动方向保持一致，别越轴（对话 A 看右、下一镜 B 也在看右 = 两人同向）。

## 五、声音设计

### 5.1 层级

成片听感 = 旁白/对白（主） + BGM 铺底（次） + 自动响度归一。旁白 BGM 开闪避（duck）。

### 5.2 角色音色：身份感优先

- 旁白说书人一套音色；每个角色一套，**气质要能区分角色**（书生≠说书人≠妖）
- 音色试听不可省：搜「气质词」（知性温暖/沉稳/温柔动听/神秘），逐角色听 2-3 个再定
- 同角色全片一个音色；妖/鬼可用特殊处理音色建立恐怖感

### 5.3 对白同步：逐镜偏移

「统一 500ms 偏移」对旁白够用，对白会**声音早于口型**。解法：给对白镜的配音记录设 `offset_ms`
（约 1000-1500ms，等人物起幅开口），渲染器按镜生效，旁白镜保持默认。**对白必须贴开口时点，旁白无所谓**——这是两类声音的本质区别。

### 5.4 时长铁律

配音/旁白 ≤ 镜长秒数 × 4 字（TTS 约 4.3-5.2 字/秒）；配音时长 + 偏移 < 镜头实际时长，否则被截断。

## 六、技术执行 SOP

### 6.1 素材 URL：公网可达是第一关卡

上游模型只能拉「公网 http(s) URL」——本机文件/内网全不行，且有三道隐形门槛：

1. **端口白名单**：非标准端口（如 18293）直接拒绝，挂到 **80/443**
2. **体积**：1.5MB PNG 会下载超时（504），压缩到 **~200KB JPEG** 秒拉（视频参考用 1280 宽足矣）
3. **Range/代理兼容**：nginx 关代理缓冲、流式传输，避免下载中断

推荐自建文件服务器（download/列表公开、上传带认证）统一管理种子图，比第三方图床稳。

### 6.2 限流与排队

视频生成有上游限流（免费档 1 次/分钟）。62 镜 ≈ 65 分钟起步——**批量入队后台排队**，别逐镜干等；期间并行做配音/BGM/文案。503 `video_queue_full` 是瞬时限流，`retry` 接口带退避即可。

### 6.3 渲染配方

- 转场 fade；旁白偏移 500ms 默认（对白镜另设）；BGM 0.3-0.35 开闪避
- 字幕白描（white-outline）44 号最通用；志怪/纪录向可略小
- 响度无需手调：自动 loudnorm -16 LUFS

### 6.4 拼接与归档

多段 xfade（0.8s fade）拼接；字幕按各段实测时长重排时间轴；产物归档作品目录（成片/字幕/台词/海报）。

## 七、质量自检清单（交付前逐项打勾）

**画面**

- [ ] 每个多镜角色全程「同一张脸」（逐段抽查，尤其远景小人）
- [ ] 无裸文生镜（全部有图锚或场景锚）
- [ ] 风格统一：无写实/动画乱跳
- [ ] 动作自然：无人偶/幻灯片式移动
- [ ] 开场镜建立了时空，结尾镜收束了情绪

**声音**

- [ ] 旁白连读成文；台词带角色口吻
- [ ] 音画同步：对白在开口时点响（非早于口型）
- [ ] 无截断：配音时长+偏移 < 镜长
- [ ] 无破音；BGM 与调性匹配、闪避开启

**技术**

- [ ] 质检：时长偏差 ≤±8%；响度 -16±2 LUFS；字幕行数 = 旁白/对白镜数
- [ ] 拼接段间过渡自然；字幕时间轴无错位
- [ ] 作品库成片/字幕/台词/海报齐全，URL 可访问

## 八、《画皮》实战复盘表（症状 → 根治）

| 症状（第一版）     | 根因                  | 根治方案（已验证）                            |
| :----------------- | :-------------------- | :-------------------------------------------- |
| 主角 26 镜认不出   | 无种子图，纯文字锚    | 全局角色种子图 + 每镜 `<Picture N>` 图锚      |
| 写实/动画乱跳      | 32 镜裸文生无参考     | 零裸文生：角色图 + 场景种子图 + 统一风格锚    |
| 转场斑斑点点       | dissolve 叠加噪场     | fade 300-400ms                                |
| 相邻镜头跳变       | 无运动承接            | 链式首尾帧（上镜末帧做下镜首帧）              |
| 人走路像假人       | 立绘静态参考          | prompt 声明「仅外貌参考、动作自然、严禁僵硬」 |
| 声音早于口型       | 统一 500ms 偏移       | 对白镜逐镜 `offset_ms`                        |
| 开场角色不像种子图 | 开场镜漏锚            | 主角出镜即锚，远景也锚                        |
| 1.5MB 图拉取失败   | 上游下载超时/端口受限 | 压缩 ~200KB + 挂标准端口                      |

---

> 一句话收束：**故事定上限，一致性保下限，声音提质感，技术保交付。**
> 先打磨剧本，再建锚点库，逐镜生产，最后用质检清单兜底——AI 视频的质量不是靠一次运气，是靠流程。
