### 复盘：镜 9「最后一排的孩子」——一次典型的"判型 > 调措辞"

**症状**：要"昏暗昭和和室里、独自坐着的孩子的剪影"，6 次生成全部跑偏：
`现代电影院满座` → `现代和室 + 水手服少女蜷坐` → `明亮和室 + 现代童装女孩背影` → `暗调但有矮桌茶具` → 候选出现 `戴眼镜的现代男性`。

**判型**：**模型系统性弱项**——"**人物 × 特定时代感（昭和）× 精细情绪（孤独）× 昏暗剪影**"四重叠加，
措辞（加"昭和""昏暗""剪影""过曝""不要现代"）**越写越失效**，模型反复滑向训练数据里的"现代明亮和室"。
不属于"锚缺失"（纯文生镜本就无角色锚），也不属于"措辞放大"（换了 5 种措辞都无效）。

**对策（改构图，而非继续重拍）**：

1. 镜 9 改为**纯物象**——空荡昏暗的旧和室、散着的坐垫、**一束放映光正照亮最里的一个空坐垫**、光尘漂浮，
   画面**没有任何人物**。→ **一次通过**。
2. 旁白同步改写：「其他孩子都走了。最后一排，还留着一个小小的位置。」（"被留下的孩子"由"空位"留白表达）
3. 镜 10 改为**風花陪坐在空位旁**（有角色锚、可控）——叙事反而更贴题：
   她坐进的正是"那个位置"的旁边，**呼应母题「观看=观众补全」（幻灯的静止画面由观看者让它流动）**。

**沉淀**：`AI 强于场景/氛围/物象，弱于"人物＋时代感＋微情绪"的组合`。
遇到四重叠加型镜头反复失败 → **不要继续调措辞**，果断降维成「**物象 + 留白**」或「**可控主体（有种子图的角色）+ 空位/背影**」。

### 其它观察

- 成片帧率 30fps、分辨率 720P（平台 `size:720P` 上限）；13 镜时长偏差 +1.4%~+2.2%，均 <±8%
- 记忆世界镜（镜 8/10）色温明显偏暖褐、现实镜偏青蓝，冷暖分制生效
- 片内文字规避有效：胶片盒/招牌/布幕均未出现可读文字（片头/片尾卡文字由渲染层添加，非模型生成）
- **修复：成片尾部静音（v2.4.1）**——首版成片音频流仅 128.4s（视频 137.7s，尾部 9.3s 无 BGM）：
  闪避滤镜 `sidechaincompress` 输出随侧链（旁白）结束而截断，**最后一条旁白之后的 BGM 段整段丢失**。
  修复（侧链 apad 补静音 + 输出链尾 apad 兜底）后重渲（render-92）：音频流 137.68s ≈ 视频流 137.70s ✓。
  教训：**"最后一条旁白远早于片尾"的结构会暴露此问题**（此前项目旁白铺到末镜，未暴露）。

## 封面 / 片头卡视觉重设计（v2.5.4 · 2026-09）

**起因**：用户反馈"海报不如视频封面好看"（旧海报 = 关键帧 + 代码绘白字）→ 先是「封面改用片头卡帧」，
继而由 AI 主导重设计片头卡本身（片头卡与发布封面同源，一处改两处受益）。

### 设计决策（含被否决的方案，留档以免走回头路）

| 方案                            | 结论                                                           |
| ------------------------------- | -------------------------------------------------------------- |
| 关键帧 + 代码绘字（旧"海报"）   | ❌ 字体与排版生硬；且每集多花一次 LLM + 文生图调用             |
| 横排居中衬线（v2.5.4 之前）     | ❌ 缩略图下偏弱，缺乏识别度                                    |
| 细明体（mingliub）竖排          | ❌ **缺简体与假名字形，渲染成方块**（已从候选表剔除）          |
| 纯衬线竖排                      | 🟡 优雅，但缩略图下笔画偏细                                    |
| 粗黑体竖排                      | 🟡 醒目，但缺"电影海报"气质                                    |
| **挂轴纸带 + 明宋竖排（定稿）** | ✅ 浅纸底深墨字 → 对比最强；和风挂轴呼应"幻灯屋"；缩略图仍可读 |

### 实现

- `workers/render.js`：`titleCardFilters()` 抽为**纯函数**（渲染与预览同源）；`stageFont()` 同时置备
  正文（雅黑 Bold）与衬线（华文宋体/宋体，自动探测）两套字体；布局为「左上系列标识 + 集号（宽字距）
  → 居中挂轴（竖排集名，逐字绘制并居中，长集名自动缩放）→ 底部细线 + 署名」，外加细内框与压暗/暗角。
- 新增 `tools/card-preview.js`：**秒级出单帧预览**，不必整集渲染即可试版（设计迭代从"80 秒/轮"降到"1 秒/轮"）。
