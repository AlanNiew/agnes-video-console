## 六、约定（防漂移 checklist）

1. **风格锚一字不改**（走模板；不逐镜改写措辞）。
2. **角色图只经角色库导入**（不手工复制 project_images 记录）。
3. **双语口径**：`narration`＝中文字幕脚本（≤秒数×4 字）；`tts_text`＝日文配音（≤秒数×7 音拍）。
4. **配色分制**：现实＝濑户内晴光＋夕凪蓝；记忆世界＝褪色胶片暖调＋光尘；悬念＝深蓝＋星白。
5. **每集一张主题场景图**（片头/片尾卡背景，沿用"夜／灯／海"符号体系）；
   **交付封面 = 片头卡帧**（渲染自动抽一帧存为作品目录 `封面.png`）。
   **片头卡视觉（v2.5.4 定稿）**：左上系列标识「幻 灯 屋」（宽字距）+ 细分隔线 + 集号 → 居中**挂轴纸带**
   （浅纸底 + 木色轴杆）内竖排**明朝/宋体**集名 → 底部细线 + 署名；外加细内框与背景压暗/暗角。
   改版用 `node tools/card-preview.js --scene <图> --subtitle "S1E04 雨の音" --out p.png` 秒级试版。
6. **交付前**跑 `GET /api/projects/:id/checklist`，全绿再渲染归档。
7. 制作完在本文件「五、各集规格」补一行，并把复盘写入 `幻灯屋-制作记录.md`。
8. **改提示词勿整段重写**：风格锚必须原样保留（平台 `ensureStyleAnchor` 已自动兜底，但仍应避免）；
   "人群中的角色看不清面目"用**背影 + 逆光 + 极小**三件套。
9. **BGM 与环境声联动**：`ambient_volume ≥0.3` 的"声音叙事"集，`bgm_volume ≤0.22`（E04 实测：
   0.35 会与雨声抢空间）——并把 `creator` 随渲染参数一并传入（片头卡署名不会自动带）。
