## 一、系列一句话

> 濑户内海港町的幻灯屋里，少女**風花**替人"放映"被遗忘的瞬间——
> 每一段记忆是一封没有寄出的信，而她自己的那封信，收件人未明。

- **时空**：濑户内海的坡道港町「潮见町」——石阶、常夜燈、雁木、渡船、旧商店街、夏祭。
- **主角**：風花（ふうか）· 16 岁 · 幻灯屋第四代放映师。
- **核心事件**：每段替一位委托人放映一卷"夜光胶片"——无法改变记忆结局，只能完成一个微小的心愿。
- **情感落点**：被"留下"的少女，学会替自己发声。

## 二、世界观与规则

**潮见町**：温暖少雨、晴天多、海面常静（夕凪）的濑户内海港町。人口渐少、空房渐多——
**風花回来，是因为只剩她回来**（现实重量）。

**幻灯屋的谱系**（家族史＝小镇史＝媒介史）：

| 时代       | 谁          | 形态                                       |
| ---------- | ----------- | ------------------------------------------ |
| 昭和初年   | 曾祖父      | 开「幻灯舗」：卖幻灯机与胶片、办幻灯会     |
| 战后       | 祖母·美纱子 | 改为「幻灯屋」，给孩子放幻灯画剧（黄金期） |
| 电视普及后 | 祖母        | 镇上影院与幻灯会都消失了，只有她没关灯     |
| 父母一代   | 父母        | 离开小镇去了城市；風花被留在祖母家         |
| 现在       | 風花        | 祖母过世，回来继承 108 卷夜光胶片          |

**规则（每段遵守，构成仪式感）**：

1. 只能在**夜里**放映；
2. 观看者**不能改变记忆的结局**，只能完成一个"微小的心愿"——说一句话、放下一件东西、多看一眼；
3. 放完的胶片会化作**星光消散**——记忆被"好好看过"才能安息（物哀）；
4. 每一段记忆只有**一次**放映机会；
5. 放映机点亮需要"**灯芯**"——風花要拿自己的一点记忆作引燃（长线张力：她放得越多，越忘掉自己为何回来）。

**媒介自省（美学内核）**：幻灯的本质是"投影静止画面、由观看者补全运动"——
**记忆正是静止的瞬间，我们自己在心里让它重新流动**。全系列反复写"观看"这件事本身。

**"灯"的谱系**（视觉母题）：港口的**常夜燈**（守护船与人）→ 幻灯屋的**放映灯**（守护记忆）→ 现代的无灯之夜。

**片内文字规避**（模型弱项）：胶片标签、信纸、招牌一律**不拍文字特写**——用"旧纸质感/素面木牌/后期贴图"处理。

## 三、主角：風花（ふうか）

| 维度     | 设定                                                                                    |
| -------- | --------------------------------------------------------------------------------------- |
| 身份     | 幻灯屋第四代放映师；祖母的继承人                                                        |
| 外观锚点 | 墨蓝长发（半扎、发尾微卷）、白衬衫 + 深蓝背带裙、胸前黄铜怀表（祖母遗物）、琥珀色眼睛   |
| 声音     | 沉静、礼貌、句尾轻（敬语）；配音用「日文·ふうか」——**名字与音色同名绑定**，观众听声识人 |
| 性格     | 看得比说得多；记住别人忽略的细节；替人着想胜过自己                                      |
| 内在矛盾 | 幼时被父母"留在"祖母家——"被留下的人"；擅长替别人传达心意，唯独自己的心意一句不说        |
| 固定台词 | 「それでは、上映いたします。」（那么，开始放映吧。）——每段放映仪式                      |
| 弧光     | 替他人放映 → 敢为自己放映（跨季长线）                                                   |

小习惯（角色辨识度素材）：放映前轻摸胸前的怀表；紧张时整理背带裙；喜欢在天台看夜里的飞机灯；
不擅长当面说话，却写得一手好明信片——"文字人格"是她无声的表达通道。

## 四、常驻角色池（分季扩建）

- **祖母·美纱子**：已故。幻灯屋第三代，战后幻灯黄金期的见证者（S2 主线）。以胶片/回忆登场。
- **商店街的人们**：面包店奶奶、修鞋匠、渡口船老大——随季节轮换登场，逐步常驻化。
- **ナナ**：幻灯屋的三花猫（低频使用；猫的跨镜一致性难，只作情绪符号，不给复杂动作）。
- **「收胶片的人」**：S1 末登场的长线人物，目的不明——与第 108 卷有关。
- **未来的同伴**（S2+ 预留）：转学生 / 少年——留给后续开发，暂不定型。

## 五、主题与母题

- **母题一「伝える」（传达）**：没说出的话、没送达的心意——每段故事的变奏。
- **母题二「观看」**：幻灯＝静止画面的连续；观看者让记忆重新流动（媒介自省）。
- **母题三「记忆与遗忘」**：遗忘不是治愈，"好好看过"才是。
- **母题四「留下与离开」**：祖母守屋 / 父母出走 / 風花归来——三重同构。
- **视觉母题**：放映光柱、胶片孔、星光、海、怀表、常夜燈、夜。

## 八、单段创作公式（每段结构模板）

1. **独白开场**（10–20s）：風花视角，引入本段主题（诗性，不剧透）。
2. **触发**：委托/一卷胶片到达（现实世界，建立本段人物）。
3. **放映仪式**：「それでは、上映いたします。」——光柱亮起（系列标志镜头）。
4. **记忆世界**（本段主视觉）：褪色胶片暖调＋光尘（与现实色温对照）；遇见那段记忆。
5. **微小行动**：完成心愿（一句话/放下/多看一眼）。
6. **回到现实**：委托人的变化 + 風花的小小思考（**不总结说教**，用一个画面收）。
7. **收尾钩子**：風花独白回响；每 2–3 段埋一次长线（祖母/胶片/收胶片的人）。

旁白纪律：全篇独白连读成文；日文配音文本 ≤ 镜头秒数 × 7 音拍（以 `tts.duration` 实测为准）；中文脚本 ≤ 秒数 × 4 字。

## 十、定位与差异化（要点）

**独特点**：① **逆旅人结构**（主角不移动，世界向她走来——"被留下"即引擎）；② **媒介自反**（明治以来的幻灯/纸芝居/影院史）；
③ **地域的具体性**（濑户内海港町，非泛日式小镇）；④ **代际同构**（家族史＝小镇史＝媒介史）；⑤ **母题是"留守的尊严"**（不是寻找/复仇/成长，而是目送）。

与《紫罗兰永恒花园》（旅人·代笔·追寻）、《虫师》（漂泊·解决）、《夏目》（归还名字）、《千年女优》（纵向史诗）的逐项对照见 `幻灯屋-考据笔记.md` §四。
