# 《幻灯屋》考据笔记（背景资料 / 定位依据）

> 用途：为系列企划提供**可核查的时代、地域、美术依据**，并明确与相近作品的差异化定位。
> 配套文档：`幻灯屋-系列企划.md`（创作蓝本）。本笔记是"论据库"，写作查细节用。

## 一、时代考据：日本「幻灯 / 纸芝居 / 小镇影院」的兴衰

### 1. 幻灯（幻燈 / gentō = magic lantern）

- **起源**：明治 13（1880）年，文部省委托东京浅草「**鶴淵幻燈舗**」制作幻灯，作为"通俗教育"工具——
  **幻灯最初是教育媒介，不是娱乐**；日清（1894）〜日俄（1904）战争期达顶峰（战况报道＋教育＋娱乐）。
- **衰退**：大正期（1912-26）电影（活動写真）兴起，幻灯退守学术/宗教/儿童玩具。
- **复兴**：昭和 1930s 中期教育界呼吁回归学校 → 1941 年文部省正式推荐 →
  1940s 战时作为国策宣传复兴（金属管制下出现**纸质/木制幻灯机**）。
- **战后高峰（占领期 1945-52）**：1948 年 CIE（民间情报教育局）每月售出 6,000 部幻灯胶片；
  **1953 年文部省调查：公立小学幻灯放映机保有率 77.3%，幻灯胶片逾 30 万本。**
- **本质**：投影**静止画面**——被称为「**動く掛図**」（会动的挂图），
  不像电影制造"动态幻觉"，**运动由观看者自行补全**。
- 1950s 社会运动（工会、反核、歌唱运动）中成为草根媒体，服务于「経験の交換」（经验交换）。

### 2. 紙芝居（街頭紙芝居）

- **诞生**：昭和 5（1930）年浅草"平絵"纸芝居，代表作《黄金バット》。
- **演出形态**：纸芝居屋骑自行车载舞台与糖果，**打拍子木（拍子木）／吹法螺贝**召集孩子，
  卖水糖·煎饼充当"入场费"。
- **招牌话术**：**「続きはまた来週」**（下周继续）——连载留悬念的祖师爷。
- **全盛**：昭和 10（1935）年东京约 2,000–2,300 业者，**每天 60–100 万儿童**观看；
  昭和 12（1937）年最盛期；战后 1946 年复活，1950 年全国约 5 万业者。
- **消亡**：1955 年电视普及 10 万台 → 1960 年 500 万台 → 纸芝居从街头消失。

### 3. 町の映画館（小镇影院）

- 昭和 33（1958）年观影人次达峰 **11 亿**；影馆数昭和 35（1960）年峰值 **7,457 馆** → 平成 5（1993）年 1,734 馆。
- 1953 年电视开播＋彩色电视普及 → 加速衰退。
- 实例：岩手一戸町「**萬代館**」——1909 年芝居小屋创业 → 昭和初年转影院，
  老式碳弧放映机，县内首位女性放映技师，夫妻二人坚守，并为学童办放映会。
- 现代复兴形态：**コミュニティシネマ**（NPO 运营的社区影院）。

### → 对企划的启示

1. **家族＝媒介史**：祖母美纱子（战后一代）在幻灯"草根黄金期"经营幻灯屋，亲历电视取代一切的年代——
   她"守屋"是一种抵抗；風花重启，是隔代接续。
2. **核心隐喻**：「幻灯＝静止画面的连续」正契合"记忆"——记忆是静止的瞬间，**观看者让它重新流动**。
3. **「続きはまた来週」** → 系列"单元＋长线钩子"的历史原型；可成为幻灯屋的传统台词。
4. **仪式元素**：拍子木／法螺贝／糖果 → 風花的放映仪式（摇铃／点灯／「それでは、上映いたします」）。
5. **"灯"的谱系**：港口的常夜燈 → 幻灯屋的放映灯 → 现代的无灯之夜。

## 二、地域考据：濑户内海港町的质感

### 视觉地标

- **常夜燈**：港口石造灯塔（现存 160 余年），日落点灯，守护船与人。
- **雁木**（がんぎ）：随潮汐**隐现**的石阶船着场（最长约 150m、24 段，形如圆形剧场）——"隐现"意象。
- **坂道と路地**：坡道与迷宫小巷（尾道"箱庭的都市"）；急勾配上贴着的聚落、石垣宅地。
- **渡船**：约 5 分钟船旅串起岛与陆。
- **造船所的起重机群**：重工业与海景并存。
- **夕凪**（ゆうなぎ）：傍晚海面平静——濑户内海代表意象。

### 生活与物产

- 气候**温暖少雨**（瀬戸内海式気候）——晴天多，**阳光是日常**（与"光"主题天然契合）。
- 柑橘（**青いレモン**·青柠檬，秋〜12 月采收）、鯛網（传统捕鲷）、練り物。
- 古町并：白壁土藏、格子户，江户〜昭和 30 年代面影。

### 当代现实质感

- 人口锐减：上島町 1950 年 15,552 人 → 2020 年 6,509 人；男木島 昭和 20 年约 1,200 人 → 今约 140 人（高龄化率约 40%）。
- **空き家激增**（小豆島逾 3,000 軒）；移住 / I ターン、地域おこし協力隊、空き家再生 NPO。
- 濑户内国际艺术节带来的"外部目光"。

### → 对企划的启示

1. 舞台从"泛日式小镇"具体化为**濑户内海的港町「潮见町」**：坡道、石阶、常夜燈、渡船、夕凪。
2. "空房/人口减少"给風花归乡以现实重量：**她回来，是因为只剩她回来**。
3. 光的谱系有地理依据：常夜燈（港）→ 幻灯屋（家）。
4. 四季风物诗：春樱 → 夏祭/花火 → 秋柠檬收成 → 冬雪与渡船。

## 三、美术考据：赛璐璐 × 光（可操作要点）

- 赛璐璐动画的光影语法：**斜射光**、**西日（夕阳）暖调**、**镜头光晕/鬼影（lens flare/ghost）**、
  同一画面**顺光＋逆光并存**、**多光源**。
- 背景技法「道路沿いのパラドクス」：为画面张力**故意制造"不合理光源"**（一张画里同时有顺光/逆光/侧光）——
  前提是"画不破绽"，手段服务于构图。
- 动画光影的目标：**「絵でしかない画面をいかに現実のように感じてもらうか」**（让"只是画"的画面有真实感）。
- 赛璐璐画法的雨/水：雨滴带轮廓线、以 2–3 色涂分光与影（**抽象化**处理），而非 CG 物理模拟。
- 色收差（chromatic aberration）在画面边缘制造"镜头感"（山田尚子/京阿尼风格）。

### → 对企划的启示

- 风格锚微调（沿用 #34 已验证锚 + 补光语汇）：
  `日本动漫赛璐璐风格，清晰墨线描边，平涂色块与硬边阴影，新海诚式通透光影，2D 手绘动画质感，电影感构图`
  → 可选加词：`斜射逆光与镜头光晕，西日暖调`（记忆段落另加`褪色胶片色、漂浮光尘`）。
- 光影分制：**现实＝濑户内晴光＋夕凪蓝**；**记忆世界＝褪色胶片暖调＋光尘**；**悬念＝深蓝＋星白**。
- 既定规避（与平台弱项一致）：**画面内文字**（招牌/信纸/胶片标签→素面或后期贴图）；
  **流体特写**（泪/雨滴"正在流"的过程→改静态光斑/痕/借代）。

## 四、定位与差异化（vs 相近作品）

| 参照作品           | 其核心结构                                            | 《幻灯屋》的差异                                                                           |
| :----------------- | :---------------------------------------------------- | :----------------------------------------------------------------------------------------- |
| 《紫罗兰永恒花园》 | 少女**旅人**·代笔人（写）·走向他人·寻找"我爱你"的含义 | 風花是**归乡者/留守者**（不移动）·放映师（看/见证）·**世界走向她**；主题是"留下"而非"追寻" |
| 《虫师》           | 银古**漂泊**·解决虫引起的怪异·规则＋单元＋物哀        | 風花**定居**一屋·不"解决"只"见证"·规则服务于"观看"而非"驱除"                               |
| 《夏目友人帐》     | 贵志**归还名字**·人与妖的羁绊·温暖单元                | 无"归还"任务·对手不是妖而是**记忆**本身·濑户内地志替代"妖怪谱系"                           |
| 《千年女优》       | **纵向**追忆一生（个人史诗）                          | **横向**小镇群像（一段一人）                                                               |
| 《海街日记》       | 家族日常·镰仓                                         | 濑户内海港町·加"奇幻装置"（幻灯）而非纯写实                                                |

**《幻灯屋》的五个独特点**：

1. **逆旅人结构**：主角不移动、不走遍世界；她是"留守者"，世界向她走来——**"被留下"从缺陷变成叙事引擎**。
2. **媒介自反**：明治以来的幻灯／纸芝居／影院史——对"**观看方式**"本身的哀愁（《紫罗兰》是书信、《虫师》是民俗，都无此层）。
3. **地域的具体性**：不是"日本小镇"，是**濑户内海的港町**（常夜燈/雁木/渡船/夕凪/青柠檬/空房）。
4. **代际同构**：家族史＝小镇史＝媒介史（祖母守屋 / 父母出走 / 風花归来）——三重"留下与离开"。
5. **母题是"留守的尊严"**：不是寻找、复仇、成长，而是**目送**——委托人都在送别，風花在"代送"。
