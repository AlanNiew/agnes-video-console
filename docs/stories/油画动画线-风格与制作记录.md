# 油画动画线 · OIL-01《播星的人》

> **这条线是什么**：工作区第三条动画风格线（前两条＝《幻灯屋》的**日式赛璐璐 2D**、《画皮·动态漫画预告》的**新国风水墨**）。
> 本文件是该线的**单一来源**：风格锚、角色库索引、成片规格、制作流水线与复盘。
> 数据侧真实资产在「角色库」（`settings.character_library`）与项目 **#47**；成片在 `data/works/《播星的人 油画动画》-47/`。
> 风格方法论依据：`docs/VIDEO_CREATION_GUIDE.md` §3.5（风格判据与评估量表）。

## 一、风格锚（**全片逐字复制，禁改措辞**）

```
后印象派厚涂油画风格动画，梵高式旋涡笔触与厚堆颜料肌理，钴蓝与铬黄高饱和撞色，可见笔触的流动感，油画布纹理，强对比戏剧性光线，逆光剪影，电影感构图，高细节
```

**写法要点（可复用到下一条线）**：`流派名（给模型先验） + 材质/笔触（锁定"画"而不是"照片"） + 配色（锁定色域） + 光线 + 构图 + 画质词`。
只写"梵高风格"会漂移成"普通油画"，只写描述词又拿不到旋涡笔触的先验——两者都要。

## 二、主题库（可扩展）

欧洲乡村与四季 ⇄ 星空/麦田/柏树/向日葵/咖啡馆夜色 ⇄ "劳动与传承"母题。
**适配面**：低结构、高纹理、大光比的场景（天空、麦浪、雪原、夜街）——这正是该风格的"场景化威力区"（§3.5 已判：有天空/戏剧光线的外景最强）。

## 六、制作流水线（本次实际执行顺序，可复用）

1. **定风格 + 定剧本**：按 §3.5 判据选风格 → 写"给这个风格量身定做"的剧本（本片＝大天空 + 麦田 + 剪影，全避开手部/流体/复杂动作）。
2. **建项目**（`POST /api/projects`）+ **出种子图**：角色图各 2 张候选（Agnes 免费档，1K/3:4）→ **看图择优** → `POST /api/characters` 入库。
3. **片头卡底图**：Agnes 2K 出 2 张 + **即梦 `jimeng-image-5.0pro` @2k 出 2 张**（顺位①，实扣 8 积分/次）→ `tools/card-preview.js` 秒级比版 → `select-image` 定稿。
4. **开镜**：本项目复用 `tools/series-new-episode.js` 的建项目/导角色/导分镜三段逻辑（写成一次性脚本 `.scratch/run-oil.js`，只对已有项目 #47 灌数据，避免重复建项目）。
5. **逐镜视频**：12 镜一次入队 → 提交器 60s 节流 → 约 20 分钟（上游 429/503 退避自愈，未产生废记录）。
6. **逐镜配音**：12/12 一次通过（秒级）。
7. **抽帧自检**：每镜 4 帧接触表 → 目视 + `/api/tasks/:id/metrics` 客观指标 → 定重拍清单。
8. **重拍**：镜2（手部微距崩）、镜11（与镜9 构图重复）→ `PATCH` 提示词 → `retakes` → `select-take` 定稿。
9. **选 BGM** → **渲染** → 核对质检报告 → 抽帧复核 → **发布包**。

## 七、复盘与教训

① **风格锚一次成片率 12/12（零失败、零跑偏）**：本风格的"物理不精确吸收率"极高——笔触、厚涂、色块本身就是"不真实"的表达，模型的解剖/材质误差被直接读作画风。与 §3.5 判据完全一致。

② **唯一崩点是手，判型＝模型弱项，对策＝改构图**（手册 §3.4 三问判型）。镜2 首版写成"老人的手从袋口抓出一把种子"，模型给出**手指黏连 + 麦粒从掌心长出来**的微距；改写成"只拍袋口与倾泻而下的种子，**不出现手、不出现人物身体**"后一次通过。
→ **该风格同样吃"手部微距"这一刀**，别因为"反正是油画"就放松构图规避。

③ **蓝调惯性**：提示词写"黄昏/落日"，模型仍反复给出**梵高标志性的钴蓝旋涡天空**（12 镜里 9 镜的天空是蓝的）。这带来极强的系列统一感，但**计划中的"盛夏金 → 深秋蓝"冷暖对比被大幅削弱**。
→ 若要保住冷暖叙事，得在**每一镜**显式写"暖色落日/金色麦浪占据画面主体、不要蓝色天空"，而不是只在首镜交代。

④ **长叠化会吃掉成片时长**：`dissolve 1200ms × 11 处 = 13.2s` 重叠，成片比标称短 **5.5%**——这是本项目**首次出现负偏差**（以往都是 +0.2%~+2.3%）。要控时长把 `transition_ms` 压到 600–900 即可；反之，**想让成片更"慢"就直接用 1200ms**，比拉长单镜便宜。

⑤ **`flash_ratio = 0` 是油画风格的重要红利**：厚涂纹理在帧间是"整体一致地流动"，不像细线稿那样出现线条蠕动/闪烁。这也解释了为什么**赛璐璐/白描/油画**这类"强笔触、弱依赖真实物理"的风格稳。

⑥ **片头卡副标题无法显式置空（平台缺口）**：`POST /api/projects/:id/render` 的 `subtitle: ''` 会被 `routes/render.js` 归一化成 `null`，于是片头卡**回落到项目名余段**——首版纸带上写的是风格名「油画动画」而不是片名。
→ 本次绕过：**副标题直接传片名**（纸带 = 片名，左上系列标识同字，片尾卡取 `title` 也正确）。
→ 平台侧建议：`subtitle: ''` 应保留为"显式空"（与 `undefined` 区分）。

⑦ **发布包的抖音竖屏封面是坏文件（平台 bug，本次已修）**：`workers/render.js` 的 `fillAspect` **图片分支沿用了 `-c:v libx264` + `.png` 后缀** → 产出"扩展名 .png、内容是裸 H.264 流"的文件（文件头 `00 00 00 01 67`），微信/浏览器/平台都打不开。
- 影响面：**S1E05、S1E06、OIL-01 的 `发布包/抖音/封面-竖屏.png` 全部中招**（已逐一重建为合法 PNG）；
- 之所以一直没被发现：e2e 只校验**宽高**（ffprobe 能从裸 H.264 里读出 720×1280），必须校验**文件头魔数**——本次已补该回归护栏（`test/mock-e2e.js`）。
- 修复：图片分支显式 `-c:v png`；版本 **v2.6.2**。

⑧ **重渲后必须"用哪个 worktree 的实例"重生成发布包**（E06 复盘 ⑤ 的原样复现）：`lib/publish-kit.js` 按**代码目录**找 `tools/publish/*.json`，平台实例（`agnes-video-console`）里只有 E01–E04 的策展 → 文案会静默降级成"标题=项目名、标签=—"。
→ 正确姿势：**渲染/生产用平台实例，发布包用创作实例**（`DATA_DIR=<主目录>\data` + `PORT=8274`）各跑一次；本次先被降级、发现后重生成才落回策展文案。

⑨ **即梦额度（顺位①/②）本轮实况**：
- 封面底图 `jimeng-image-5.0pro` @2k：**2 次请求、实扣 16 积分**（8/次，与 E06 标定一致），原生 2560×1440 16:9，比 Agnes 场景图更适合做封面（构图可控、零裁切）；
- 英雄镜头 `seedance2.0` 720p/10s：提交即 **`ExceedConcurrencyLimit`（ret=1310）→ 任务直接 failed**（standard 会员并发上限），且**该错误未被 `core/provider-policy.js` 归类**（既不属于环境未就绪，也不属于"生成失败"），因此**没有自动回退、也没有重试**——护栏说好的"回退免费档"在这条路径上是空的。
→ 平台侧建议：把 `ExceedConcurrencyLimit` 归入**可退避重试**（并发会自然释放），重试耗尽再回退免费档。

⑩ **双实例工作锁的真实代价：接管＝换代码版本**。本次为跑发布包起了 8274（`agnes-content`，v2.6.0）实例；主实例（v2.6.2）被重启的间隙里，**8274 在 30s 内接管了工作锁并跑完了渲染 #118**——成片本身没问题，但**归档段的竖屏封面走的是 2.6.0 的旧代码**，于是又生成了一个坏 PNG。
→ 纪律要补一条：**做完生产就立刻停掉第二个实例**；重启主实例后先确认锁归属再提交任务。

## 八、风格评估（§3.5 量表 · 五维 1–5 分）

| 维度          | 权重 | 评分 | 依据                                                                        |

| 运动稳定      | 25%  | 4    | `flash_ratio=0`（12/12）、`motion_mean` 0.8–7.3 无异常；**未逐帧看片，待人工确认** |

| 跨场景一致性  | 15%  | 5    | 日/夜/室内外 12 场景同一"画家"，无色域漂移                                   |
| 构图美感      | 10%  | 5    | 多镜可直接当独立油画看（镜11/镜12 尤佳）                                     |

**加权可用性分 ≈ 4.55 → ≥4.0：可作主力风格。**（评分含主观项，"运动稳定"必须由人看片复核后才作数——本表已如实标注。）
