# tools/ —— 创作驱动脚本（可复用资产）

这些脚本用于**程序化驱动**本平台的创作流程。控制台 UI 适合单项目精修；脚本适合**系列批量生产**
（一集 13 镜 × N 集，手工编排既慢又易漏参数——实测曾漏设某镜的角色引用开关）。

## 文件

| 脚本                    | 用途                                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------- |
| `agnes-api.js`          | API 助手（Node 原生 fetch，零依赖）。**中文 JSON 勿走 PowerShell curl——会乱码**，一律经此脚本 |
| `series-new-episode.js` | **系列开集脚手架**：建项目 → 从角色库导入角色 → 批量导入分镜 → 逐镜提交视频 → 逐镜配音        |
| `episodes/`             | 每一集的配置 JSON（分镜表 + 角色 + 风格锚），与成片一一对应                                   |

## 快速开始

```bash
# 1) 准备本集配置：复制 tools/episodes/_template.json 并填写
# 2) 开集（默认提交视频 + 配音；--no-submit / --no-tts 可跳过，便于先检查分镜）
node tools/series-new-episode.js tools/episodes/S1E03.json --no-submit
# 3) 视频完成后：选 BGM → 渲染 → 质检
```

## 约定

- **服务地址**：环境变量 `AGNES_BASE`（默认 `http://127.0.0.1:8273`）。
- **风格锚**：`style` 会被逐镜追加到 `video_prompt`（跨镜一致性关键，勿逐镜改写措辞）。
- **角色编号**：`characters` 数组顺序 = 项目内 `<Picture 1>…<Picture N>` 的编号顺序；
  镜头的 `ref_image_ids_index` 用数组下标指定本镜出场角色（省略 = 引用全部定稿角色图）。
- **双语字幕**：`narration` 是字幕脚本（中文，≤秒数×4 字）；`tts_text` 是配音文本
  （日文，≤秒数×7 音拍）；两者不同时成片自动输出双语两行。
- **角色库**：角色先在控制台用「⭐ 收藏到角色库」入库，`characters` 填库 id
  （`GET /api/characters` 可查）。
- **限流**：视频提交上游限流 1 次/分钟，脚本会一次入队、后台按序提交（13 镜约 13–15 分钟）。
